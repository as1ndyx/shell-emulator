# Эмулятор языка оболочки ОС

Практическая работа №1 по дисциплине «Конфигурационное управление».
Вариант №22, этап 1 «REPL».

## Общее описание

Консольное приложение (CLI) на Go, имитирующее работу командной строки
UNIX-подобной ОС. На первом этапе реализован минимальный прототип: диалог
с пользователем уже работает, а сами команды пока являются заглушками.

Возможности этапа:

* приглашение к вводу формируется из реальных данных ОС — `username@hostname:~$`;
* простой парсер разделяет ввод на команду и аргументы по пробелам;
* команды-заглушки `ls` и `cd` печатают своё имя и полученные аргументы;
* команда `exit` завершает работу эмулятора;
* неизвестная команда и неверные аргументы выводят сообщение об ошибке,
  не прерывая сессию.

## Описание функций и настроек

Настроек и параметров командной строки на этом этапе нет — они появятся
на этапе 2 «Конфигурация».

Исходный код находится в каталоге `src`, тесты — в каталоге `tests`.

| Файл | Функция | Назначение |
| --- | --- | --- |
| `src/main.go` | `main` | Точка входа: запускает REPL на стандартных потоках. |
| `src/shell/prompt.go` | `Prompt` | Собирает приглашение вида `username@hostname:~$`. |
| `src/shell/prompt.go` | `UserName` | Имя текущего пользователя ОС (`unknown` при ошибке). |
| `src/shell/prompt.go` | `HostName` | Имя машины (`localhost` при ошибке). |
| `src/shell/parser.go` | `Parse` | Разбивает строку ввода на команду и аргументы по пробелам. |
| `src/shell/parser.go` | `Command` | Структура с именем команды и списком её аргументов. |
| `src/shell/commands.go` | `Execute` | Выполняет команду и возвращает её вывод или ошибку. |
| `src/shell/commands.go` | `ErrExit` | Признак того, что запрошено завершение работы. |
| `src/shell/repl.go` | `Run` | Цикл «чтение — выполнение — вывод». |
| `src/shell/repl.go` | `handle` | Обрабатывает одну строку ввода, печатает вывод или ошибку. |

Поддерживаемые команды:

| Команда | Поведение |
| --- | --- |
| `ls [аргументы]` | Заглушка: печатает `ls: <аргументы>`. |
| `cd [аргументы]` | Заглушка: печатает `cd: <аргументы>`. |
| `exit` | Завершает работу эмулятора. Аргументов не принимает. |

## Сборка и запуск

```sh
make run          # запустить эмулятор
make build        # собрать исполняемый файл в bin/emulator
make test         # запустить тесты
make fmt          # отформатировать код
make clean        # удалить артефакты сборки
```

Запуск без make:

```sh
./run.sh
```

## Примеры использования

Интерактивная сессия:

```text
as1ndyx@MacBook-Pro:~$ ls -l /home
ls: -l /home
as1ndyx@MacBook-Pro:~$ cd ..
cd: ..
as1ndyx@MacBook-Pro:~$ cd
cd: аргументов нет
as1ndyx@MacBook-Pro:~$ exit
```

Обработка ошибок:

```text
as1ndyx@MacBook-Pro:~$ qwerty 1 2
ошибка: qwerty: команда не найдена
as1ndyx@MacBook-Pro:~$ exit extra
ошибка: exit: аргументы не поддерживаются
as1ndyx@MacBook-Pro:~$ exit
```
