# Эмулятор языка оболочки ОС

Практическая работа №1 по дисциплине «Конфигурационное управление».
Вариант №22, этапы 1–4.

## Общее описание

Консольное приложение (CLI) на Go, имитирующее работу командной строки
UNIX-подобной ОС. Виртуальная файловая система (VFS) загружается с диска
в оперативную память, и команды работают только с ней.

Возможности:

* приглашение к вводу формируется из реальных данных ОС вместе с текущим
  каталогом — `username@hostname:~/docs$` — либо задаётся параметром;
* простой парсер разделяет ввод на команду и аргументы по пробелам;
* команды `ls`, `cd`, `cat`, `rev` и `uptime` работают с VFS в памяти;
* служебные команды `conf-dump` и `vfs-tree` выводят параметры эмулятора
  и дерево VFS;
* команда `exit` завершает работу эмулятора;
* неизвестная команда и неверные аргументы выводят сообщение об ошибке,
  не прерывая сессию;
* команды могут выполняться из стартового скрипта, при этом на экране
  отображается и ввод, и вывод;
* при запуске печатается отладочный список всех заданных параметров.

## Параметры командной строки

| Параметр | Значение |
| --- | --- |
| `-vfs <путь>` | Путь к директории-источнику VFS. Без параметра эмулятор работает без VFS. |
| `-prompt <текст>` | Приглашение к вводу. По умолчанию собирается из данных ОС. |
| `-script <путь>` | Путь к стартовому скрипту с командами эмулятора. |

Пример запуска со всеми параметрами:

```sh
go run ./src -vfs vfs/deep -prompt "myshell$" -script examples/start.txt
```

Отладочный вывод при запуске:

```text
[debug] параметры запуска эмулятора:
[debug]   vfs = vfs/deep
[debug]   prompt = myshell$
[debug]   script = examples/start.txt
[debug] VFS загружена в память из vfs/deep
```

## Команды

| Команда | Поведение |
| --- | --- |
| `ls [путь]` | Содержимое текущего или указанного каталога. Каталоги помечаются `/`. Для файла выводит его имя. |
| `cd [путь]` | Переход в каталог. Без аргумента — в корень VFS. |
| `cat <файл>...` | Содержимое одного или нескольких файлов. |
| `rev <файл>...` | Строки файлов, перевёрнутые задом наперёд. |
| `uptime` | Текущее время и время работы эмулятора. |
| `conf-dump` | Параметры эмулятора в формате ключ-значение. |
| `vfs-tree` | Дерево загруженной в память VFS. |
| `exit` | Завершает работу эмулятора. |

Пути в командах понимаются так же, как в UNIX:

| Путь | Значение |
| --- | --- |
| `notes/todo.txt` | относительно текущего каталога |
| `/etc` или `~/etc` | от корня VFS |
| `..` | родительский каталог; выше корня подняться нельзя |
| `.` | текущий каталог |

Сообщения об ошибках:

| Ситуация | Сообщение |
| --- | --- |
| пути нет | `ls: nosuchdir: нет такого файла или каталога` |
| `cd` в файл | `cd: readme.md: не является каталогом` |
| `cat` или `rev` каталога | `cat: docs: это каталог` |
| нет обязательного аргумента | `cat: укажите файл` |
| лишние аргументы | `cd: слишком много аргументов` |
| VFS не загружена | `ls: VFS не загружена, укажите параметр -vfs` |

## Виртуальная файловая система

Источником VFS служит обычная директория на диске. При запуске она целиком
читается в оперативную память, после чего диск не используется: все операции
выполняются над деревом в памяти, исходные файлы не изменяются. Проверить это
можно скриптом `scripts/run_vfs_readonly.sh`, который сравнивает контрольные
суммы файлов до и после работы эмулятора.

Если путь не существует или указывает на файл, а не на директорию, эмулятор
сообщает об ошибке и завершает работу с кодом возврата 1.

Готовые варианты VFS находятся в каталоге `vfs`:

| Каталог | Содержимое |
| --- | --- |
| `vfs/minimal` | Минимальный вариант: один файл. |
| `vfs/flat` | Несколько файлов без вложенных каталогов. |
| `vfs/deep` | Три уровня вложенности файлов и папок. |

Пример вывода команды `vfs-tree`:

```text
deep/
  docs/
    notes/
      draft.txt
      todo.txt
    overview.txt
  etc/
    config.ini
  readme.md
  src/
    app/
      main.txt
    lib/
      util.txt
```

## Стартовый скрипт

Стартовый скрипт — текстовый файл, в котором каждая строка является командой
эмулятора. Команды выполняются последовательно, ошибочные строки пропускаются
с сообщением об ошибке. Введённые команды дублируются на экране, поэтому вывод
выглядит как диалог с пользователем. Если в скрипте встретилась команда `exit`,
работа завершается, иначе эмулятор переходит в интерактивный режим.

Готовые скрипты находятся в каталоге `examples`:

| Файл | Назначение |
| --- | --- |
| `examples/start.txt` | Обычная работа с VFS. |
| `examples/with-errors.txt` | Пропуск ошибочных строк. |
| `examples/with-exit.txt` | Завершение работы командой `exit` внутри скрипта. |
| `examples/full-test.txt` | Команды всех этапов, включая работу с VFS и ошибки. |
| `examples/stage4.txt` | Все режимы команд `ls`, `cd`, `cat`, `rev`, `uptime` и их ошибки. |

## Описание функций

Исходный код находится в каталоге `src`, тесты — в каталоге `tests`.

| Файл | Функция | Назначение |
| --- | --- | --- |
| `src/main.go` | `main` | Точка входа: разбирает параметры и запускает эмулятор. |
| `src/shell/config.go` | `Config` | Структура с параметрами запуска эмулятора. |
| `src/shell/config.go` | `ParseFlags` | Разбирает аргументы командной строки. |
| `src/shell/config.go` | `Pairs` | Возвращает параметры в формате ключ-значение. |
| `src/shell/config.go` | `PrintDebug` | Печатает отладочный список параметров. |
| `src/shell/session.go` | `Session` | Состояние эмулятора: параметры, VFS, текущий каталог, время запуска. |
| `src/shell/session.go` | `PromptString` | Приглашение из параметра либо из данных ОС с текущим каталогом. |
| `src/shell/session.go` | `resolve` | Превращает путь из команды в путь от корня VFS. |
| `src/shell/session.go` | `lookup` | Находит файл или каталог по пути, иначе возвращает ошибку. |
| `src/shell/prompt.go` | `Prompt`, `PromptIn` | Собирают приглашение вида `username@hostname:~$`. |
| `src/shell/prompt.go` | `UserName`, `HostName` | Имя пользователя и машины из данных ОС. |
| `src/shell/parser.go` | `Parse` | Разбивает строку ввода на команду и аргументы. |
| `src/shell/commands.go` | `Execute` | Находит команду в таблице и выполняет её. |
| `src/shell/commands.go` | `cmdUptime` | Команда `uptime`. |
| `src/shell/fs_commands.go` | `cmdLs`, `cmdCd` | Команды `ls` и `cd`. |
| `src/shell/fs_commands.go` | `cmdCat`, `cmdRev` | Команды `cat` и `rev`. |
| `src/shell/repl.go` | `Run` | Цикл «чтение — выполнение — вывод». |
| `src/shell/script.go` | `Start` | Отладочный вывод, загрузка VFS, скрипт, интерактивный режим. |
| `src/shell/vfs.go` | `Node` | Узел VFS в памяти: файл или каталог. |
| `src/shell/vfs.go` | `LoadVFS` | Загружает директорию с диска в память. |
| `src/shell/vfs.go` | `Tree` | Возвращает дерево VFS в виде текста. |

## Сборка и запуск

```sh
make run          # запустить эмулятор
make build        # собрать исполняемый файл в bin/emulator
make test         # запустить тесты
make fmt          # отформатировать код
make clean        # удалить артефакты сборки
```

Запуск без make:

```sh
./run.sh
```

Скрипты реальной ОС находятся в каталоге `scripts`:

```sh
./scripts/run_default.sh       # запуск без параметров
./scripts/run_prompt.sh        # параметр -prompt
./scripts/run_vfs.sh           # параметр -vfs
./scripts/run_script.sh        # параметр -script
./scripts/run_all.sh           # все параметры и обработка ошибок

./scripts/run_vfs_minimal.sh   # минимальная VFS
./scripts/run_vfs_flat.sh      # VFS из нескольких файлов
./scripts/run_vfs_deep.sh      # VFS с тремя уровнями вложенности
./scripts/run_vfs_errors.sh    # ошибки загрузки VFS
./scripts/run_vfs_readonly.sh  # проверка, что диск не изменяется

./scripts/run_stage4.sh        # все команды этапа 4
```

## Примеры использования

Работа с каталогами и файлами:

```text
as1ndyx@MacBook-Pro:~$ ls
docs/  etc/  readme.md  src/
as1ndyx@MacBook-Pro:~$ cd docs/notes
as1ndyx@MacBook-Pro:~/docs/notes$ ls
draft.txt  todo.txt
as1ndyx@MacBook-Pro:~/docs/notes$ cat todo.txt
Список задач.
as1ndyx@MacBook-Pro:~/docs/notes$ rev todo.txt
.чадаз косипС
as1ndyx@MacBook-Pro:~/docs/notes$ cd /etc
as1ndyx@MacBook-Pro:~/etc$ cd
as1ndyx@MacBook-Pro:~$ uptime
21:01:12 up 0:00:42
```

Обработка ошибок:

```text
as1ndyx@MacBook-Pro:~$ cd readme.md
ошибка: cd: readme.md: не является каталогом
as1ndyx@MacBook-Pro:~$ cat docs
ошибка: cat: docs: это каталог
as1ndyx@MacBook-Pro:~$ qwerty 1 2
ошибка: qwerty: команда не найдена
```

Вывод параметров командой `conf-dump`:

```text
myshell$ conf-dump
vfs = vfs/deep
prompt = myshell$
script = examples/start.txt
```
